# 学生信息统计工具

读取学生信息 JSON 文件，统计成绩并支持按学号查询，可将结果导出为文本报告。

## 功能

- 从 `data/students.json` 读取学生数据
- 校验每条记录的 `id` / `name` / `score`，无效记录自动跳过
- 统计：平均分、最高分、最低分、及格人数
- 按学号查询学生姓名和分数
- 导出统计报告到 `output/report.txt`
- 异常处理：文件不存在、空文件、JSON 格式错误、空数组

## 运行环境

- 操作系统：Windows 10 / 11
- 编译器：g++ 16.2.0（MinGW-W64）
- C++ 标准：C++17
- 第三方库：nlohmann/json（已内置在 `include/nlohmann/json.hpp`，无需另外安装）

## 如何运行

**1. 进入项目根目录**（必须在根目录，程序用相对路径找数据）

    cd D:\code\student-statistics

**2. 创建编译输出目录**（首次运行必须做，否则编译会失败）

    mkdir build

**3. 编译**

    g++ -std=c++17 -I include src\main.cpp -o build\app.exe

**4. 运行**

    .\build\app.exe

## 输入数据格式

文件位置：`data/students.json`

结构：JSON 数组，每个元素是一个学生对象。

    [
      {
        "id": "2026001",
        "name": "Alice",
        "score": 92
      },
      {
        "id": "2026002",
        "name": "Bob",
        "score": 76
      }
    ]

字段说明：

| 字段 | 类型 | 说明 |
|---|---|---|
| id | 字符串 | 学号，必须带引号 |
| name | 字符串 | 姓名 |
| score | 数字 | 分数，不能带引号 |

校验规则：任意字段缺失或类型不匹配的记录会被跳过，并在终端提示，不会导致程序中断。

## 输出内容

启动后显示主菜单：

    已加载 2 名学生，跳过 0 条无效数据

    ===== 菜单 =====
      1. 查询总体数据
      2. 按学号查询学生
      3. 导出结果到文件
      0. 退出
    请输入选项：

输入 `1` 显示：

    ===== 总体数据 =====
      学生人数   2
      平均分     84
      最高分     92
      最低分     76
      及格人数   2

输入 `2` 后按提示输入学号，输入 `-1` 返回菜单。

输入 `3` 生成 `output/report.txt`。

## 已知限制

1. **及格线固定为 60 分**，培养方案未规定，按常规取值。
2. **仅支持 UTF-8 编码的 JSON 文件**，GBK 编码会解析失败。
3. **不支持嵌套结构**，只接受扁平的 `[{...}]` 数组。
4. **数据一次性读入内存**，数据量很大时占用内存较高。
5. **报告文件每次覆盖**，不保留历史版本。
6. **仅适用于 Windows**，使用了 `SetConsoleOutputCP` 处理中文输出；Linux 需另行处理。
